# Static Code Analysis — Documented Issues (`energy_system.py`)

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| **Use of insecure `eval()` (`B307` / `W0123`)** | Security (Bandit: Medium / Pylint) | 63 | `eval(adjustment)` executes arbitrary Python expressions from user input, creating a code injection vulnerability (CWE-78). | Imported `ast` and replaced `eval(adjustment)` with safe `ast.literal_eval(adjustment)`. |
| **Mutable default argument (`W0102`)** | Bug (Pylint) | 12 | `history=[]` in `def record_reading(meter_id, units, history=[])` is shared across all function calls, causing unexpected state retention. | Changed default value to `history=None` and initialized `if history is None: history = []` inside the function. |
| **Overly broad bare `except:` (`W0702` / `E722`)** | Bug / Quality (Pylint & Flake8) | 44 | Bare `except:` in `load_meter_data()` catches all exceptions (including `SystemExit` and `KeyboardInterrupt`) and hides real errors. | Replaced bare `except:` with specific exceptions: `except (OSError, json.JSONDecodeError):`. |
| **Resource leak & missing encoding (`R1732` / `W1514`)** | Quality (Pylint) | 42, 48 | `open()` is called without a `with` context manager (file handle `f` in `load_meter_data` is never closed) and without explicit text encoding. | Used `with open(file, ..., encoding="utf-8") as file_handle:` to ensure safe encoding and automatic file closure. |
| **Negative meter reading & negative bill** | Logical Bug (Manual Inspection) | 12, 55, 60 | `record_reading("M-03", -50)` accepts negative consumption units, producing an invalid negative electricity bill (`Bill M-03: -192.50`). | Validated `units` in `record_reading()` and `compute_bill()` so negative readings are clamped to `0`. |
| **Global variable rebinding (`W0603`)** | Design / Quality (Pylint) | 27, 40 | `global` keyword used in `raise_rates()` and `load_meter_data()` makes state harder to track and maintain. | Replaced individual rate globals with a `RATE_TIERS` list updated in place, and mutated `meters` dictionary using `.clear()` and `.update()`. |
| **Unused import & PEP 8 violations (`F401`, `E302`, `E501`, `C0114`, `C0116`)** | Style (Flake8 & Pylint) | 1, 2, 12–68 | Unused `import sys`, missing module/function docstrings, only 1 blank line before functions, and lines exceeding 79 characters. | Removed `import sys`, added docstrings to module and all functions, added 2 blank lines between top-level functions, and wrapped lines to <= 79 characters. |
